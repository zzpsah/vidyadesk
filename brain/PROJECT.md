# Project Brain — Project

VidyaDesk is the unified project hub for UMV Tethali. It coordinates access to existing school software while preserving each repository's ownership of its data and workflows.

Primary outcome: one coherent school-facing workspace without duplicating data, bypassing source-system controls or claiming unverified integrations are live.

Constraints: Hindi-medium government higher secondary school context; academic session 2026–2027; private education data is sensitive; no production mutations without explicit approval.
