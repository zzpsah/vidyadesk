# Decisions

- Start with VidyaDesk as the pilot; do not bulk-copy identical skill sets into every repository.
- Skills remain instructions, not privileged execution tools.
- GitHub Actions is the reliable event-driven hook for every PR/push.
- MCP servers and specialist subagents are used only where the host exposes them and their permissions are explicit.
- No production deployment, merge, secret changes or database writes are included.
