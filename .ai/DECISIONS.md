# Decisions

- VidyaDesk remains a project hub and integration shell, not a replacement for owner applications.
- Source-of-truth ownership remains in each existing project.
- UDISE+ and eShikshaKosh remain distinct.
- OFSS is treated as admissions evidence, not a standalone school application.
- Private student/staff records stay unavailable until authentication, fixed-school scope, verified source mapping and audit controls are accepted.
- Report Central aggregate credentials must never be widened to student-level access.
- No production deployment, provider write, database migration, portal submission or VPS configuration change without separate explicit approval.
- Feature branches and pull requests are required; main remains the production branch.
